# Live elevator quotation workflow audit

**Status: IN PROGRESS · 2026-10-30**

## Goal

Verify the live development workflow for every API-supported quotation purpose,
including upstream Work Intake → lead/survey → installation quotation and new
AMC onboarding → paid AMC → renewal, through purpose-appropriate lifecycle and
customer review. Record expected behavior, browser/API/test evidence,
observations, fixes, and anything blocked by unavailable external evidence.
Protect the existing authorization, immutable-revision, tax, customer tenancy,
and conversion rules.

Live checks use development identities and synthetic elevator data. Mutating
checks may create clearly labeled development records; they must not send a
customer email or alter production data. Any delivery action must be an
explicitly controlled development recipient. The mock prototype is design
evidence only.
